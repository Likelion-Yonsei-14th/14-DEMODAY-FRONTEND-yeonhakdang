# 로그인 후 기기 간 정보 유지

게스트의 입력·결과·명단은 브라우저에 저장합니다. 로그인한 사용자의 완료된 분석 입력과 친구 명단은 `/api/me/analysis-profile`에서 복원하고 변경을 자동 저장합니다. 무료 분석 결과는 저장된 입력으로 다시 계산합니다. 구매 내역은 기존 보관함 API를 사용합니다.

첫 조회 완료 전에는 입력을 막고 업로드하지 않습니다. 조회 실패 시 기존 데이터를 보호하고 다시 불러오기 버튼을 제공합니다. 게스트 분석 후 로그인하면 현재 분석을 채택하고 계정의 기존 친구 명단을 병합합니다. 기존 기기의 로컬 전용 분석은 계정에 저장된 프로필이 없을 때 이전합니다. 다른 계정 소유의 로컬 분석은 채택하지 않습니다.

저장은 순차 처리하고 revision으로 다른 탭의 오래된 덮어쓰기를 막습니다. 충돌 안내가 나오면 새로고침해 최신 계정 정보를 불러옵니다. 저장 실패 시 안내하며, 로그아웃은 진행 중인 저장 완료를 기다립니다. 다시 분석하기는 새 분석을 완료할 때 저장된 최신 분석을 대체합니다. 과거 분석 이력 기능은 아닙니다.

백엔드 `2540af5` 이상의 배포가 먼저 필요합니다. 환경변수 추가 없음. Render에서 해당 배포가 Live, Vercel이 Ready인지 확인합니다.

## 실계정 확인

1. 이전 정보가 있는 원래 브라우저에서 최신 화면으로 새로고침 후 같은 카카오 계정으로 로그인합니다. 이미 로그인했다면 새로고침 시 이전됩니다.
2. 새 시크릿 창이나 다른 기기에서 같은 계정으로 로그인하고 이름·생년월일·무료 결과·친구 명단을 확인합니다.
3. 정보 수정 후 다른 창을 새로고침해 최신 값 복원을 확인합니다.
4. 로그아웃·재로그인 후 복원, 다른 카카오 계정의 분리, 탈퇴 후 삭제를 확인합니다.

로그아웃이나 브라우저 저장소 삭제로 이미 사라진 로컬 정보는 소급 복구할 수 없습니다. 서버에 저장되지 않은 예전 데이터는 원래 브라우저에서 이전해야 합니다.
