# 게스트 분석과 회원 로그인

- 첫 화면에서 `게스트로 시작하기`와 `카카오 로그인`을 선택합니다. 게스트는 계정 생성 없이 무료 분석을 확인할 수 있습니다. 이름·생년월일 입력은 로그인으로 취급하지 않습니다. 카카오 로그인은 메뉴나 결과 맨 아래에서도 선택합니다.
- 카카오 로그인은 기존 회원 기능을 사용합니다. 첫 화면에서 로그인하면 정보 입력으로, 이미 분석한 결과에서 로그인하면 같은 결과 화면으로 복귀합니다. 로그인 직전 저장하는 입력·결과 상태는 초기화하지 않습니다.
- 로그인 상태는 메뉴에서 확인합니다. 결과 화면은 분석부터 보여주고, 맨 아래에 카카오 로그인(게스트만)과 다시 분석하기를 배치합니다.
- 결과 화면과 메뉴의 `다시 분석하기`는 현재 입력, 분석 완료 표시, 저장된 요약 ID 연결, 이전 사람의 친구·초대 정보를 초기화합니다. 로그인·동의·서버 계정·구매 및 결제 기록은 유지합니다. 서버에 이미 저장한 결과나 주문을 삭제하지 않습니다.
- 새 분석의 탐색 순서는 첫 화면 → 새 입력 화면입니다. 입력 화면의 뒤로가기와 브라우저 뒤로가기는 첫 화면으로 돌아가며, 이전 사람의 결과 화면으로 돌아가지 않습니다.
- 게스트에게는 로그아웃 대신 카카오 로그인 버튼을 표시합니다. 로그인 화면에서도 무료 결과나 입력 화면으로 돌아갈 수 있습니다. 구매는 기존처럼 회원 로그인과 동의가 필요합니다.
- 동기 합격자 명단(4번 화면군)과 카드 공유(5번 화면군)는 현재 게스트 테스트를 위해 로그인 없이 이용할 수 있습니다. 결과 버튼·하단 탭·메뉴·직접 해시 주소 모두 허용합니다. 회원 보관함·구매 및 서버 API의 인증은 그대로 유지합니다.
- 명단은 실제 입시 합격자 명단이 아니라 친구의 사주 궁합 순위이며, 현재 기기에 저장합니다. 계정 간 양방향 자동 등록·동기화 기능은 아직 없습니다. 카드 공유는 내 결과를 이미지 또는 초대 링크로 전달하는 기능입니다.
- 게스트용 서버 계정이나 새 인증 방식을 추가하지 않았습니다. 전체 결과와 입력의 기기 간 복원 기능도 이번 변경 범위에 포함되지 않습니다.

검증: `npm test`의 분석 초기화 테스트로 로그인·구매·진행 결제 보존 및 개인정보 초기화를 확인합니다. 카카오 실계정 로그인은 배포 후 브라우저에서 확인해야 합니다.

## 로그인 없이 수동 테스트

1. Vercel에서 최신 커밋 배포가 Ready인지 확인하고 사이트를 새로고침합니다.
2. 게스트로 시작하기 → 샘플 이름·생년월일 입력 → 무료 결과를 확인합니다.
3. 내 학과 카드 공유하기 → 학과 결과 카드 / 명단 카드, 카톡 1:1 / 스토리 9:16 전환과 이미지 저장·링크 복사를 확인합니다. 회원 로그인 화면이 나오지 않아야 합니다.
4. 친구 명단: 일반 창에서 샘플 A로 분석하고 공유 화면의 초대 링크를 복사합니다. 시크릿 창 또는 다른 브라우저에서 링크를 열고 샘플 B로 분석하면 B의 명단에 A가 등록됩니다. 서로의 브라우저가 자동 동기화되는 것은 아닙니다. 반대편 등록은 B의 초대 링크를 A 쪽에서 열어 확인합니다.
5. 결과 하단 다시 분석하기 → 이름·날짜가 빈 입력 화면 → 상단 뒤로가기 → 첫 화면으로 돌아가는지 확인합니다.
6. 무료 분석·명단·공유만 게스트로 테스트할 수 있습니다. 서버 회원 보관함·주문·결제는 실제 로그인과 각 서비스 설정이 필요합니다. 카카오톡 직접 공유는 카카오 로그인과 별개의 JavaScript SDK 설정 또는 기기의 공유 기능에 영향을 받으므로 이미지 저장·링크 복사부터 확인합니다.
