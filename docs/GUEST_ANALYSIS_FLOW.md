# 게스트 분석과 회원 로그인

- 첫 화면은 `게스트로 시작하기` 버튼 하나로 계정 생성 없이 무료 분석을 시작합니다. 이름·생년월일 입력은 로그인으로 취급하지 않습니다. 카카오 로그인은 메뉴나 결과 맨 아래에서 선택합니다.
- 카카오 로그인은 기존 회원 기능을 사용합니다. 첫 화면에서 로그인하면 정보 입력으로, 이미 분석한 결과에서 로그인하면 같은 결과 화면으로 복귀합니다. 로그인 직전 저장하는 입력·결과 상태는 초기화하지 않습니다.
- 로그인 상태는 메뉴에서 확인합니다. 결과 화면은 분석부터 보여주고, 맨 아래에 카카오 로그인(게스트만)과 다시 분석하기를 배치합니다.
- 결과 화면과 메뉴의 `다시 분석하기`는 현재 입력, 분석 완료 표시, 저장된 요약 ID 연결, 이전 사람의 친구·초대 정보를 초기화합니다. 로그인·동의·서버 계정·구매 및 결제 기록은 유지합니다. 서버에 이미 저장한 결과나 주문을 삭제하지 않습니다.
- 새 분석의 탐색 순서는 첫 화면 → 새 입력 화면입니다. 입력 화면의 뒤로가기와 브라우저 뒤로가기는 첫 화면으로 돌아가며, 이전 사람의 결과 화면으로 돌아가지 않습니다.
- 게스트에게는 로그아웃 대신 카카오 로그인 버튼을 표시합니다. 로그인 화면에서도 무료 결과나 입력 화면으로 돌아갈 수 있습니다. 구매는 기존처럼 회원 로그인과 동의가 필요합니다.
- 게스트용 서버 계정이나 새 인증 방식을 추가하지 않았습니다. 전체 결과와 입력의 기기 간 복원 기능도 이번 변경 범위에 포함되지 않습니다.

검증: `npm test`의 분석 초기화 테스트로 로그인·구매·진행 결제 보존 및 개인정보 초기화를 확인합니다. 카카오 실계정 로그인은 배포 후 브라우저에서 확인해야 합니다.
