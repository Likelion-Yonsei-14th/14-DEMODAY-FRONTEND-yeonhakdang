# 입력 스크롤과 공유 이미지

## 입력 화면

입력 화면은 TopBar → ScreenScroll → 고정된 분석 버튼 구조입니다. 기존의 고정 높이(634px) 내부 스크롤을 제거해서 ‘태어난 시간을 몰라요’ 안내나 음력·윤달 항목이 늘어나도 입력 영역 안에서 끝까지 스크롤할 수 있게 했습니다.

## 인스타 스토리

웹사이트가 사용하는 Web Share API는 대상 앱을 강제로 지정할 수 없습니다. 브라우저·운영체제·설치 앱에 따라 공유 목록과 Instagram 노출 여부가 달라집니다.

- 인스타 스토리 버튼 → 9:16 이미지 준비 → 미리보기·선택 화면
- ‘휴대폰 공유 목록 열기’는 사용자 클릭에서 이미지 파일을 전달합니다.
- 지원하지 않거나 권한이 거절되면 화면을 닫거나 조용히 끝내지 않고 저장 방법을 안내합니다.
- ‘이미지 저장하고 직접 올리기’ → 인스타 앱에서 스토리 만들기 → 저장한 사진 선택
- 인앱 브라우저에서는 이미지 미리보기를 길게 눌러 저장할 수 있습니다.
- 이미지 생성은 최대 20초 후 실패 안내로 전환해 무한 대기를 막습니다.

## 저장 이미지 생성 방식

프론트의 분석 결과(이름·추천 학과·점수·친구 명단)와 기존 캐릭터 그림을 React 카드 템플릿에 배치하고, `html-to-image`로 3배 해상도 PNG를 만듭니다. 새 AI 그림을 생성하거나 백엔드에서 이미지를 생성하는 방식이 아닙니다.

- 정사각형: 1080×1080
- 스토리: 1080×1920
- 이미지 속 ‘프로필 링크’·‘링크’ 자리표시 문구를 실제 서비스 주소로 교체했습니다.
- PNG 안의 주소는 클릭 가능한 링크가 아닙니다. 초대 URL은 ‘링크 복사’로 따로 전달합니다.
- 현재 초대 URL은 이름·생년월일·양력/음력·윤달·출생시간을 인코딩한 데이터를 포함합니다. 암호화나 서버 계정 초대 토큰 방식은 아닙니다.

## 수동 확인

1. 짧은 화면에서 이름·날짜 입력 → 시간 모름 체크 → 안내 끝까지 스크롤 및 분석 버튼 확인
2. 음력·윤달·날짜 오류 상태에서도 입력 항목이 잘리지 않는지 확인
3. 공유에서 인스타 스토리 클릭 → 미리보기와 두 선택 버튼 확인
4. 파일 공유 미지원 브라우저에서 저장 방법 안내가 남는지 확인
5. 정사각형·스토리 PNG의 이름·학과·사이트 주소가 미리보기와 같은지 확인

자동 검증은 코드·공유 API 모의 테스트이며, 실제 휴대폰의 Instagram 설치 상태와 네이티브 공유 목록은 기기에서 확인해야 합니다.
