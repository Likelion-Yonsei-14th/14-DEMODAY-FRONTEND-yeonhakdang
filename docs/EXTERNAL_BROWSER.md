# 인앱 브라우저에서 외부 브라우저로 이동

- iPhone Instagram은 비공식 `x-safari-…` 호출을 제거했습니다. 버튼이 Safari 전환을 보장하는 것처럼 보이지 않도록 ‘링크 복사’와 앱의 외부 브라우저 메뉴 안내를 제공합니다.
- 주소는 이 탭의 최초 진입 주소를 유지하므로 초대 링크가 화면 전환으로 사라져도 함께 복사됩니다.
- 카카오톡·Android 등에서 기존 외부 이동을 시도할 수 있는 경우에는 시도 후 화면이 계속 보이거나 호출이 예외를 내면 수동 안내로 전환합니다. 알림만 잠깐 띄우는 대신 주소·복사 버튼·방법을 계속 표시합니다.
- 클립보드가 막혀 있으면 주소 입력란을 길게 눌러 직접 복사할 수 있습니다.
- 이동은 선택 사항입니다. ‘이대로 계속하기’와 닫기로 원래 화면에서 계속 이용합니다.
- 다른 브라우저는 쿠키·기기 저장소를 공유하지 않으므로 로그인과 입력 상태가 그대로 이전된다고 보장하지 않습니다.
- iPad의 데스크톱 형태 Mobile UA도 iOS로 판별합니다.

수동 확인: 인스타그램 앱에서 링크를 새로 열고 안내에서 링크 복사 → Safari 앱을 직접 열어 주소창에 붙여넣습니다. 앱의 ⋯ 또는 공유 메뉴에 외부 브라우저 항목이 있으면 그 항목도 사용할 수 있습니다. 메뉴 위치·명칭은 앱 버전에 따라 다를 수 있습니다.

자동 검증은 UA별 분기, 초대 주소 보존, 수동 전환 및 이동 예외 처리 테스트입니다. 실제 iPhone Instagram의 네이티브 메뉴·클립보드는 배포 후 실기기로 확인해야 합니다.
