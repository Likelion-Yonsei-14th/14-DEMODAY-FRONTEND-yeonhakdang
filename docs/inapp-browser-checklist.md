# 인앱 브라우저 → 외부 브라우저 열기 · 실기기 체크리스트

9-4 시트의 "Safari로 열기 / 브라우저로 열기" (`lib/externalBrowser.ts`).
배포 주소의 **친구 초대 링크**(`/?invite=…`)를 각 앱 채팅/DM으로 보내 놓고 눌러서 시작한다.

공통 확인
- [ ] 첫 진입 때 9-4 시트가 뜬다 (같은 탭에서는 한 번만)
- [ ] 외부 브라우저가 열린 주소에 `?invite=`가 그대로 있고, 초대 랜딩(1-2)에 초대한 친구 이름이 나온다
- [ ] 인앱으로 돌아오면 시트가 닫혀 있다
- [ ] "이대로 계속하기"는 시트만 닫는다

| 기기 · 앱 | 버튼 문구 | 안내 박스 | 눌렀을 때 기대 동작 | 결과 |
| --- | --- | --- | --- | --- |
| 아이폰 · 카카오톡 | Safari로 열기 | ⋯ 오른쪽 아래 메뉴 → Safari로 열기 | Safari로 전환 | |
| 아이폰 · 인스타그램 | Safari로 열기 | ⋯ 오른쪽 위 ⋯ → 외부 브라우저에서 열기 | Safari로 전환 **또는** 1.5초 뒤 안내 토스트 (x-safari- 는 보장 안 됨) | |
| 안드로이드 · 카카오톡 | 브라우저로 열기 | ⋮ 오른쪽 아래 ⋮ → 다른 브라우저로 열기 | 기본 브라우저로 전환 | |
| 안드로이드 · 인스타그램 | 브라우저로 열기 | ⋯ 오른쪽 위 ⋯ → 외부 브라우저에서 열기 | Chrome으로 전환 (Chrome 없으면 fallback 주소로 이동) | |

추가로 볼 것
- [ ] 인앱에서 새로고침한 뒤 눌러도 `?invite=`가 유지된다
- [ ] 아이폰 인스타그램에서 전환이 안 될 때, 안내 문구대로 수동으로 열면 초대 링크가 그대로다
- 기록: 기기 모델 / OS 버전 / 앱 버전을 결과 칸에 같이 적는다
